# Napakoe BOT

1. `npm install`
2. Скопируйте `.env.example` → `.env` и заполните.
3. В Discord Developer Portal включите **Server Members Intent** и **Message Content Intent**.
4. Права бота: рекомендуется `Administrator` (бэкапы, антикраш, аудит-логи).
   Роль бота должна стоять **выше** роли AFK и ролей, которые он выдаёт.
5. `npm start`

Дашборд: `http://127.0.0.1:3000` (пароль — `DASHBOARD_PASSWORD`).
Список команд — `/help`.
